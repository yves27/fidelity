Guide d'installation — Supabase (5 minutes)
📋 Étapes
1
Allez sur supabase.com → créez un compte gratuit → New project (choisissez la région la plus proche).
2
Dans votre projet : menu gauche → SQL Editor → collez et exécutez le schéma SQL ci-contre (bouton "Copier le SQL").
3
Menu gauche → Project Settings → API → copiez Project URL et anon public key.
4
Collez-les dans les champs ci-dessus → Enregistrer → Tester la connexion.
5
Importez votre fichier XLSX comme d'habitude — les données seront automatiquement envoyées vers Supabase.
