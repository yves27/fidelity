🔗 Logique de matching (Déjà client ?)

L'email est le premier critère de matching. Si un email est trouvé, les points s'ajoutent.
Si pas d'email, le système compare le numéro de téléphone.
Si aucun match : nouveau client créé avec 0 point historique.

Guide d'installation — Google Apps Script
📋 Étapes à suivre
1
Ouvrez Google Sheets et créez un nouveau classeur nommé "Mass'In Fidélité". Laissez-le vide, le script créera les feuilles automatiquement.
2
Dans le menu Sheets : Extensions → Apps Script. Un éditeur de code s'ouvre.
3
Supprimez le code existant, puis collez intégralement le code ci-contre (bouton "Copier le code").
4
Cliquez sur Déployer → Nouveau déploiement. Type : Application Web. Exécuter en tant que : Moi. Accès : Toute personne.
5
Cliquez Déployer, autorisez les permissions, puis copiez l'URL de type …/exec et collez-la dans le champ ci-dessus.
6
Cliquez "Tester la connexion" pour valider, puis "Sauvegarder vers Sheets" pour envoyer vos données actuelles.
Note : Si l'app est ouverte en file://, servez-la via un serveur local : python -m http.server 8080 puis ouvrez http://localhost:8080.
